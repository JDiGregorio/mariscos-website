# Mariscos Danzarina del Mar

Página web de Mariscos Danzarina del Mar.

## Cómo abrir la página

**Sin instalar programas**

1. Descarga la carpeta del proyecto. Si viene en un archivo ZIP, haz clic derecho y selecciona **Extraer todo**.
2. Abre la carpeta **Mariscos**.
3. Busca el archivo **index.html** y haz doble clic sobre él.
4. La página se abrirá en tu navegador.
